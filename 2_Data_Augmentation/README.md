# Data augmentation

Synthetic training-data generation and transformations of existing symbolic vocal MIDI.

## Projects

- [`markov_chain_data_augmenter`](markov_chain_data_augmenter/) — Samples new vocal sequences from learned pitch-transition and duration distributions, and augments existing MIDI.
- [`mix_vocals_by_bar`](mix_vocals_by_bar/) — Builds new vocal MIDI by tempo-normalizing, splitting, recombining, and transposing bars.
- [`mix_vocals_midi`](mix_vocals_midi/) — Combines timing patterns and pitches from different vocal performances into hybrid MIDI.

These project directories were moved from `Data_Generation/` without altering their original files.
