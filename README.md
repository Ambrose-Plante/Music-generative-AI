# Music-generative-AI

This repository contains the code used for Maximus, a platform for the creation of vocal melodies using generative AI. "Data Generation" contains the code for an original optical music recognition (OMR) software that renders PDF score pages as images, automatically detects musical symbols (staves, notes, incidentals, etc), and applies rules to convert the musical score to midi. It also contains code for a Django platform to aid in the matching of lyrical syllables to corresponding musical notes. "Vocal generation" contains the code for preprocessing, GAN architecture, training, and post-processing of the generated vocal melodies. "spatial transcriptomics" contains work for the analysis of clinical histological, genetic, and epigenetic data. "Utilities" contains code for miscellaneous projects including automated language Anki deck generation, lecture transcript-resource matching, and a few other utilities.
