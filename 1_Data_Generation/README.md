# Data generation

Upstream acquisition and construction of symbolic music data.

## Projects

- [`pdf_to_midi`](pdf_to_midi/) — Template-based optical music recognition from sheet-music PDFs, with reconstruction and export of MIDI.
- [`phoneme_alignmenment_react_app`](phoneme_alignmenment_react_app/) — React editor for manually aligning phonetic syllables to vocal MIDI note events and reviewing annotations against audio.

MIDI augmentation projects, including `vocals_by_bar_with_chord`, are organized in [`2_Data_Augmentation/`](../2_Data_Augmentation/).
